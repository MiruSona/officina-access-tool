사용법

준비 (처음 한 번)

  • 친구에게 줄 zip 은 메인 PC 에서 저장소의 Test\make-friend-zip.ps1 로 만든다. 다운로드 폴더에 생긴다.
  • zip 안에는 homegames-join.exe 와 join.conf 두 파일이 같은 폴더로 들어 있다.

친구가 할 일

  1. zip 을 「모두 압축 풀기」로 푼다.
  2. homegames-join.exe 실행 → UAC 「예」. SmartScreen 이 막으면 「추가 정보 → 실행」.
  3. 이름을 넣는다.
  4. 화면에 뜬 확인 코드 6자리를 디스코드로 알려 준다. 창을 닫았다 다시 켜도 이어서 기다린다.

내가 할 일

  1. 이 화면의 이름·확인 코드가 친구가 알려 준 코드와 같은지 본다.
  2. 같으면 「승인」, 다르면 「거절」.
  3. 승인하면 친구 exe 가 알아서 진짜 터널로 갈아타고 끝난다.
  4. 게임 접속 주소는 터널 서버 IP 10.183.26.1 이다. 친구 exe 도 끝날 때 이 주소를 띄운다 (포트는 따로 알려 준다).

주의

  • 한 번에 한 명씩 가입시킨다. 모두 같은 부트스트랩 키를 써서 동시에 하면 꼬인다.
  • 같은 zip 을 여러 친구가 써도 된다. 단 공개된 곳에 올리지 않는다.
  • zip 이 퍼졌으면 미니PC 에서 sudo bash install.sh --web-addr <미니PC LAN IP> --admin-pc <메인 PC LAN IP> --rotate-bootstrap 을 돌리고, make-friend-zip.ps1 로 zip 을 다시 만든다. exe 는 그대로, 이미 가입한 친구도 그대로다.
  • 다시 가입하려면 homegames-join.exe --rejoin.
  • 메인 PC 의 시험 터널 bootstrap-test 가 켜져 있으면 친구 가입 전에 끈다.
