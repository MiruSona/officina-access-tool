# 코드 서명 정책

친구용 가입 exe `homegames-join.exe` 하나만 서명한다. 서명할 파일은 **이 저장소 소스를 GitHub Actions 가 빌드한 것만** 이고, 서명 요청은 저장소 소유자가 승인한다.
SignPath Foundation(오픈소스 무료 코드 서명) 신청 조건에 맞춘 문서다. 영어 요약은 맨 끝에 있다.

## 1. 서명 대상

| 파일 | 서명 | 까닭 |
| --- | --- | --- |
| `homegames-join.exe` (Windows amd64) | 한다 | 친구 PC 에서 돈다. Windows Defender·SmartScreen 오탐을 줄인다 |
| `accessd` (Linux 데몬) | 안 한다 | 소유자 자신의 서버에만 깐다 |

## 2. 빌드 출처

- 소스 : `https://github.com/MiruSona/officina-access-tool` 의 이 저장소뿐이다. 밖에서 받은 바이너리를 섞지 않는다.
- 빌드 : `.github/workflows/build.yml` (GitHub 호스트 러너 `ubuntu-latest`). 로컬에서 빌드한 파일은 서명에 넘기지 않는다.
- 빌드 단계 : `go vet` → `go test` → `go-winres` 로 버전 정보·매니페스트 넣기 → `go build -trimpath` → `SHA256SUMS`.
- 의존 모듈은 `go.sum` 으로 고정되고, 빌드 도구 `go-winres` 는 판(`v0.3.3`)을 못박아 설치한다.

## 3. 역할

| 역할 | 누구 |
| --- | --- |
| 작성자·리뷰어 | 저장소 소유자 MiruSona |
| 서명 요청 승인 | 저장소 소유자 MiruSona (GitHub·SignPath 계정 모두 MFA 사용) |

밖의 기여(PR)는 소유자가 검토해 `main` 에 합친 뒤에만 릴리스에 들어간다.

## 4. 릴리스 절차

1. `main` 에서 시험이 통과한 커밋에 `cmd/homegames-join/winres/winres.json` 의 판 번호를 올린다. 태그와 winres.json 판이 다르면 CI 가 멈춘다.
2. 태그 `vX.Y.Z` 를 푸시한다.
3. 워크플로가 빌드하고 산출물(artifact)을 올린다. SignPath 승인 뒤에는 이 자리에서 서명 요청을 보내고 소유자가 승인한다.
4. 워크플로가 GitHub Release 에 `homegames-join.exe` · `accessd` · `SHA256SUMS` 를 붙인다.

## 5. 이 프로그램이 친구 PC 에 하는 일 (전부)

코드 기준 : `cmd/homegames-join/main.go` · `internal/joinflow/` · `internal/wgwin/`.

| 무엇 | 어떻게 |
| --- | --- |
| 관리자 권한 요청 | 매니페스트는 `asInvoker`. 관리자가 아니면 자신을 `runas` 로 다시 띄워 UAC 를 한 번 묻는다. 「아니요」면 아무것도 안 하고 끝난다 |
| 상태 폴더 만들기 | `%ProgramData%\HomeGames\` 를 만들고 `icacls` 로 주인을 Administrators, 권한을 SYSTEM·Administrators 만으로 바꾼다. 안에 키·상태(`join.json`)와 터널 설정 `home-games-join.conf` · `home-games.conf` 를 쓴다 |
| WireGuard 설치 | `%ProgramFiles%\WireGuard\wireguard.exe` 가 없을 때만 `https://download.wireguard.com/windows-client/wireguard-amd64-1.1.1.msi` 를 `%TEMP%` 에 받아 **SHA256 을 대조한 뒤** `msiexec /i … /qn DO_NOT_LAUNCH=1` 로 설치한다. 받은 파일은 끝나면 지운다 |
| 터널 서비스 설치·삭제 | `wireguard.exe /installtunnelservice <conf>` 로 Windows 서비스 `WireGuardTunnel$home-games-join`(가입용 임시), `WireGuardTunnel$home-games`(본 터널)를 깐다. 가입이 끝나면 임시 터널은 `/uninstalltunnelservice` 로 지운다. 본 터널은 부팅 때 자동으로 켜진다 |
| 가입 서버와 통신 | 임시 터널 안에서 `join.conf` 에 적힌 서버 IP·포트로 HTTP 요청(가입 요청·승인 상태 묻기)을 보낸다. 공개키·이름·프로그램 판 문자열만 보내고 비밀키는 보내지 않는다 |
| 연결 확인 | `PING.EXE` 로 서버 터널 IP 에 핑 3번 |

하지 않는 일 : 시작 프로그램 등록, 방화벽 규칙 직접 수정, hosts 파일 수정, 다른 프로그램 내려받기(WireGuard MSI 말고), 자기 업데이트.

## 6. 제거 방법

관리자 PowerShell 에서 :

```powershell
& "$env:ProgramFiles\WireGuard\wireguard.exe" /uninstalltunnelservice home-games
& "$env:ProgramFiles\WireGuard\wireguard.exe" /uninstalltunnelservice home-games-join
Remove-Item -Recurse -Force "$env:ProgramData\HomeGames"
```

WireGuard 자체는 「설정 → 앱 → 설치된 앱」에서 WireGuard 를 제거한다.

## 7. 연락처

문제·오탐 신고는 GitHub Issues : `https://github.com/MiruSona/officina-access-tool/issues`

## English summary

- **Signed file:** `homegames-join.exe` only (Windows amd64). The Linux daemon `accessd` is not signed.
- **Build:** only from this repository's source, built by GitHub Actions (`.github/workflows/build.yml`, GitHub-hosted runner). Locally built binaries are never submitted for signing. Dependencies are pinned by `go.sum`; the build tool `go-winres` is pinned to `v0.3.3`.
- **Roles:** author, reviewer and signing approver is the repository owner, MiruSona (MFA enabled on GitHub and SignPath). External contributions enter a release only after owner review and merge into `main`.
- **Release:** bump the version in `winres.json`, push tag `vX.Y.Z`, CI builds, submits for signing (after SignPath onboarding), owner approves, CI attaches `homegames-join.exe`, `accessd` and `SHA256SUMS` to the GitHub Release.
- **System changes made by the program:**
  - Asks for elevation once (manifest is `asInvoker`; it relaunches itself with `runas`). If UAC is declined it exits without changes.
  - Creates `%ProgramData%\HomeGames\` restricted to SYSTEM and Administrators (via `icacls`), and stores its key, state file and tunnel configs there.
  - If WireGuard is not installed, downloads the official WireGuard MSI (`download.wireguard.com`, fixed version 1.1.1) to `%TEMP%`, verifies its SHA-256, and installs it silently with `msiexec`.
  - Installs WireGuard tunnel services (`WireGuardTunnel$home-games-join` temporarily, `WireGuardTunnel$home-games` permanently, auto-start) and removes the temporary one.
  - Talks over HTTP, inside the temporary tunnel, to the join server named in `join.conf` (sends only the public key, a nickname and the client version string), and pings the server's tunnel IP.
  - It does not add startup entries, edit firewall rules or the hosts file, download anything except the WireGuard MSI, or update itself.
- **Uninstall:** `wireguard.exe /uninstalltunnelservice home-games` (and `home-games-join`), delete `%ProgramData%\HomeGames`, then uninstall WireGuard from Windows Settings.
- **Contact:** GitHub Issues of this repository.
